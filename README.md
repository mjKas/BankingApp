BankingApp is a secure banking application developed by Manuja Rajakaruna as part of the practical assessment for the Critical Systems Development MSc module offered by the University of Staffordshire, UK.

The project demonstrates the development of a modern banking system using secure authentication and backend technologies, including features such as user registration, encrypted password management, JWT-based authentication, and two-factor authentication (2FA).

## Technologies Used
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- MySQL


## Features
- User registration and login
- Password encryption using Spring Security
- JWT token-based authentication
- Two-factor authentication (2FA)
- Secure REST APIs
